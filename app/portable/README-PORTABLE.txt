Mirlo (portable build)
======================

No installation: Mirlo runs from this folder.

  1. Extract this ZIP anywhere you can write to.
  2. Run mirlo.exe.

Everything Mirlo stores (settings, logs and the browser profile with your
Google session) lives in the "data" folder created next to mirlo.exe. To
remove every trace, delete the whole extracted folder. Keep the files
together: if you move the portable copy, move the "data" folder with it.

Updates are manual
------------------

Mirlo still checks for new versions and tells you when one exists, but
portable copies do not install updates automatically. Download the new
portable ZIP from:

  https://github.com/4lefernandezc/mirlo/releases

and replace mirlo.exe (keep your "data" folder).

Windows SmartScreen
-------------------

The binaries are not code-signed yet, so Windows may warn on first run:
choose "More info" -> "Run anyway".
